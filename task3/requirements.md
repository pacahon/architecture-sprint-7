### Требования к безопасности

* Все каналы связи защищены TLS-шифрованием
* Строгий контроль прав доступа на основе принципа наименьших привилегий
* Шифрование чувствительных данных на уровне приложения для дальнейшего хранения в БД (токенизация, хранение хэша биометрии или номера авто вместо оригинальных данных)
* Логирование действий для дальнейшего аудита (аутентификация, изменение биометрических данных, события авторизации)


### Протоколы аутентификации и авторизации

* MFA при обновлении списка устройств
* OAuth 2.0 для взаимодействия мобильного приложения с платформой партнера
* Использование RBAC-модели для организации прав доступа к функционалу умного дома

### Взаимодействие между системами предприятия и внешней платформой

* Аутентификация происходит с помощью OAuth 2.0
* Авторизация происходит на стороне системы с использованием RBAC-модели
* После подтверждения доступа система отправляет синхронный REST API запрос во внешнюю платформу.
* Результатом операции должно быть выполнение команды запрашиваемым устройством.
